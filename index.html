01作品Work

Gemini 逐字稿大師 Gemini Transcription Master

2026/01 – 2026/09

長音檔轉逐字稿的純前端工具，解決 AI API 單次請求長度限制，以及長時間轉錄中途失敗就得整段重來的問題。 A frontend-only tool that turns long audio into transcripts. It works around the AI API's per-request length limit and removes the need to restart a long job when it fails midway.

  • PASS實測 1 小時錄音約 5 分鐘完成（自動切成 12 段）；以人工聽打約 4 小時估算，節省 95% 以上時間。A 1-hour recording finishes in about 5 minutes (split into 12 chunks), over 95% faster than an estimated 4 hours by hand.
  • INFO以 Web Audio API 在瀏覽器端切成 5 分鐘片段，最多 3 段同時送 Gemini 轉錄後依時間合併。Splits audio into 5-minute chunks in the browser with the Web Audio API, transcribes up to 3 at a time with Gemini, and merges them in order.
  • INFO保存每段進度可斷點續傳；API 失敗時以指數退避自動重試（最多 3 次）。Saves progress per chunk so jobs can resume; failed API calls retry with exponential backoff (up to 3 times).
  • INFO支援逐字稿與時間戳編輯、TXT／SRT 匯出；音檔不經自建伺服器。Editable transcript and timestamps with TXT/SRT export; audio never passes through a self-hosted server.

統一發票智能對獎 Smart Invoice Checker

2026/01 – 2026/09

電子發票對獎 Web App，解決逐張手動比對號碼費時又容易看錯的問題：掃描 QR Code 即可對獎，收件匣的電子發票可一次批次檢查。 An e-invoice lottery checker that replaces slow, error-prone manual matching: scan a QR code to check instantly, or batch-check every e-invoice in your inbox.

  • PASS以 Vitest 建立自動化測試：6 期財政部真實開獎號碼、各獎級邊界、末三碼 000–999 窮舉，加上 18,000 組隨機比對，共 24,132 組全數通過。Vitest suite built on six real draws, every prize-tier boundary, an exhaustive 000–999 sweep and 18,000 random cross-checks: 24,132 cases, all passing.
  • INFO設計 6 層開獎資料來源備援（含 GitHub Actions 每日同步的官方快照），每層 4 秒逾時，失效即自動切換。Six fallback data sources (including an official snapshot synced daily by GitHub Actions), each with a 4-second timeout and automatic failover.
  • INFO支援手動輸入、QR Code、Gmail 共 3 種對獎方式；QR Code 免呼叫 AI 即可對獎，辨識不到時以 Gemini Vision 備援。Three ways to check: manual entry, QR code and Gmail. QR scanning works without AI, with Gemini Vision as a fallback.
  • INFO以 Google OAuth 2.0 取得授權後，透過 Gmail API 批次掃描收件匣中的電子發票。After Google OAuth 2.0 consent, batch-scans inbox e-invoices through the Gmail API.
