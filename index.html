Gemini 逐字稿大師

個人專案・2026 年 1 月至 9 月Side project · Jan–Sep 2026

把長音檔轉成逐字稿的網頁工具。AI API 一次能吃的長度有限，長時間轉錄中途失敗又得整段重來，所以我讓它在瀏覽器裡把音檔切段、分批送出，再照時間接回去。 A web tool that turns long audio into transcripts. AI APIs cap how much you can send at once, and a long job that fails midway has to start over, so it splits the audio in the browser, sends the pieces in batches and stitches them back in order.

  • 1 小時的錄音大約 5 分鐘轉完；人工聽打估計要 4 小時。A 1-hour recording takes about 5 minutes; typing it by hand would take an estimated 4 hours.
  • 用 Web Audio API 切成 5 分鐘一段，最多 3 段同時送 Gemini。Web Audio API cuts it into 5-minute chunks, up to 3 sent to Gemini at a time.
  • 每段進度都會保存，斷線可以接著跑；API 失敗會自動重試，最多 3 次。Progress is saved per chunk so a job can resume; failed calls retry up to 3 times.
  • 可以直接改逐字稿和時間戳，匯出 TXT／SRT。音檔不會經過我的伺服器。Edit the text and timestamps, then export TXT or SRT. Audio never touches my server.

統一發票智能對獎

個人專案・2026 年 1 月至 9 月Side project · Jan–Sep 2026

一張一張對發票號碼很花時間，也容易看錯。這個工具可以掃 QR Code 馬上對獎，也能一次檢查 Gmail 收件匣裡所有的電子發票。 Checking receipts one number at a time is slow and easy to get wrong. This app checks a receipt from its QR code instantly, or goes through every e-invoice in your Gmail inbox at once.

  • 用 Vitest 寫了 24,132 組測試，全部通過：包含 6 期財政部真實開獎號碼、每個獎級的邊界、末三碼 000 到 999 全部跑一遍，再加 18,000 組隨機比對。24,132 Vitest cases, all passing: six real draws, every prize-tier boundary, every last-three-digit combination from 000 to 999, and 18,000 random checks.
  • 開獎資料有 6 個來源輪流備援，其中一個是 GitHub Actions 每天同步的官方快照；每個來源等 4 秒，沒回應就換下一個。Six fallback sources for draw data, one of them an official snapshot synced daily by GitHub Actions; each gets 4 seconds before the next one takes over.
  • 手動輸入、QR Code、Gmail 三種對法。掃 QR Code 不用呼叫 AI，讀不到才交給 Gemini Vision。Three ways to check: typing, QR code and Gmail. QR scanning needs no AI; Gemini Vision only steps in when a code can't be read.
